# Reading library data schema (v2)

> GENERATED by course-engine/reading/apply.py. Edit it in the engine
> (`course-engine/reading/SCHEMA.md`) and re-apply, not here.

Single source of truth for a reading text: one JSON file at
`content/readings/{level}/{slug}.json`. Everything a student sees is generated
from it and nothing is maintained by hand:

| Generated | By |
|---|---|
| `{reading_dir}/{level}/{slug}.html` | `scripts/build_reading_page.py` |
| `assets/audio/reading/{level}/{slug}.mp3` | `scripts/generate_reading_audio.py` |

The texts are the site's own content and are never generated or overwritten by
the engine. The machinery around them is: `scripts/reading_engine/`,
`scripts/build_reading_page.py`, `scripts/generate_reading_audio.py`,
`scripts/check_reading.py`, `assets/css/reading.css` and
`assets/js/reading.js` are all vendored copies, replaced wholesale on the next
`apply`. Fix a bug in the engine, not in a site.

## Checks

```bash
python3 scripts/check_reading.py --warnings
```

The one it exists for: **a glossary headword that never occurs in its own
passage** is defined and then never shown to the reader, and produces no build
error at all. Everything else in this schema is cheap to check at the same
time.

## Shape

```jsonc
{
  "id": "a1-reading-ma-journee",     // unique; conventionally {level}-reading-{slug}
  "level": "A1",                     // must match the folder it sits in
  "slug": "ma-journee",              // must match the filename
  "order": 6,                        // optional; sorts within a topic group
  "topic": "everyday",               // a key of TOPIC_LABELS in the site's strings
  "title": "Une journée ordinaire",
  "subtitle": "One sentence. It is the page's standfirst and the card's blurb.",
  "description": "Used for <meta name=description>.",
  "source": "authored for this site; no source document",
  "provenance": "new",               // as-published | edited | rewritten | merged | new
  "narrator": "female",              // female | male | omitted (rotates by slug)

  "passage": [                       // one string per paragraph; the only markup
    "A paragraph.",                  // allowed is *italics*, for a title or a
    "*Le Monde* l'a écrit."          // case name. Asterisks are stripped before
  ],                                 // narration and become <em> on the page.

  "images": [ /* see below */ ],
  "vocabulary": [ /* see below */ ],
  "exercises": [ /* schema: see assets/js/exercises.js */ ],
  "discussion": ["Open questions. No right answers."],
  "grammar": ["present-simple"],     // optional filter tags
  "audio": { "duration_label": "1:04" }
}
```

A paragraph is classified automatically, so nothing has to be tagged by hand:
a short unpunctuated line is a **section heading**, a line opening with a name
and a colon is a **dialogue turn**, the first prose paragraph carries the
**drop cap**. That is why a text mixing a prose introduction with a dialogue
comes out set correctly without the author thinking about it.

## Images

```jsonc
{
  "src": "01.jpg",            // in assets/img/reading/{level}/{slug}/, or
                              // "b2/esope/03.png" to share another text's set
  "after": 3,                 // 0-based index of the paragraph it follows
  "wide": true,               // optional; for a map, a flag, a document --
                              // anything read for detail
  "alt": "What is in the frame, for somebody who cannot see it",
  "caption": "*Title* — Artist, year. Then a sentence, if it is an analogue.",
  "source": "commons:File:Foo.jpg",   // or a local gallery filename
  "relation": "depicts",              // depicts | analogue — see below

  // Written only when the licence requires a credit, and printed under the
  // picture.
  "licence": "CC BY-SA 4.0",
  "author": "Name of the photographer or institution",
  "source_url": "https://commons.wikimedia.org/wiki/File:...",
  "credit_prefix": "Photo"            // optional; a satellite composite is
                                      // not a photograph
}
```

**`relation` is the field that keeps the library honest.** A period painting
can be doing one of two quite different jobs:

- `depicts` — the picture is of the thing. The Bastille being stormed; a
  portrait of Marie Curie; the actual text of an edict.
- `analogue` — a period work standing in for something it is not. A siege
  painting over a text about online security; a Dutch harbour over a text
  about Marseille.

An analogue is a good illustration and a bad photograph, and the caption is
what decides which the reader takes it for. A caption reading only
*"\*Dordrecht\* — Elias Pieter van Bommel, 1871."* over a text about Lyon
tells a reader they are looking at Lyon. So an analogue's caption must carry a
sentence saying what it is doing there, and `check_reading.py --warnings`
reports one that does not.

If `relation` is absent it is inferred: a `commons:` source is a `depicts`, a
local gallery file is an `analogue`. Set it explicitly wherever that is wrong.

Rights are not a judgement call: public domain and CC0 are used as they are;
CC BY, CC BY-SA and equivalent attribution licences are used with the licence
and author recorded on the image and printed under it; anything carrying **NC**
or **ND** is refused, because ND forbids the resize every image goes through
and NC puts a condition on the whole site.

## Vocabulary

```jsonc
{
  "term": "se lever",         // dictionary form, with its article or pronoun
  "definition": "sortir du lit le matin",
  "match": "me lève"          // optional: pin the exact surface form
}
```

The builder highlights the first occurrence of each headword in the passage and
hangs the definition off it, and the same list prints as **Key Vocabulary**,
which is also what a screen reader reads (each highlight carries
`aria-describedby` pointing at its entry).

Finding "me lève" from "se lever" is the engine's job, and it is per-language:
the rules live in `scripts/reading_engine/langs/<lang>.py`. They deliberately
over-generate, because a form that occurs in no text costs nothing while a
missing one is a bug. Use `match` when the passage uses a form the rules
cannot reach, or when a word has two senses and the wrong one is being claimed.

### Choosing the words

The students are Portuguese speakers, which changes what is worth a line:

- **Skip transparent cognates.** A word a Brazilian reader gets for free spends
  a line and teaches nothing.
- **Prefer false friends.** These look easy, so no difficulty heuristic will
  ever select them, and they are where a reader misunderstands a sentence while
  feeling certain they understood it. House style marks them:
  `"... — attention : ce n'est pas ..."`.
- **Prefer the idiomatic** — phrasal and pronominal verbs, collocations,
  everyday concrete words — over learned abstractions.

### How many

| Level | Pre-A1 | A1 | A2 | B1 | B2 | C1 | C2 |
|---|---|---|---|---|---|---|---|
| Entries | 4–8 | 5–8 | 6–10 | 8–12 | 10–15 | 10–16 | 10–18 |

Guidance, not a rule. A text with a genuinely technical subject earns more; no
text should be padded to reach a number.

## Audio

Narration is fingerprinted on the exact text sent to the TTS service, plus the
voice and rate — so editing a title, an exercise or a caption does **not**
force a re-record, and editing a passage re-records exactly that file.
Anything that rewrites a passage changes what the narrator says, so
`generate_reading_audio.py` has to run afterwards.
